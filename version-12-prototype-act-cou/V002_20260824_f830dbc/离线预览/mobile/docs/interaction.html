门店员工活动分享移动端返回移动端原型

功能说明

继续从原服务助手移动端进入，复用原 SA 活动选择、二维码、海报、本人数据与用户聚合页。

员工侧

  • 按账号、唯一门店、活动投放和任一命中角色过滤可分享活动。
  • 无任何授权角色时，服务助手首页不展示活动分享入口；原型另提供无权限态评审页。
  • “我的二维码 / 我的分享数据”作为身份卡下方同级快捷入口，不再挤占标题栏。
  • 选择活动数量不设业务上限；生成前选择固定时长或长期有效。
  • 二维码冻结员工、账号、全部角色、主角色、命中角色、门店和活动集合。
  • “我的二维码”仅展示当前账号，可再次保存原码或原码海报，不支持手动作废。

海报与本人报表

  • 员工可编辑标题、副标题和扫码引导语，也可上传 JPG/PNG 自定义底图。
  • 系统统一叠加二维码、门店与员工姓名；员工头像可隐藏，员工角色和二维码有效期不进入客户海报。
  • “我的分享数据”仅看当前账号，无导出、无排名。
  • 活动、卡券和客户数据均按最终来源员工账号隔离；组合活动按子活动拆开。
  • 卡券只展示已核销/核销率。

关键交互

场景页面反馈规则
选择活动普通活动和组合活动均为可选对象，角色或门店未命中时不展示。空允许分享角色表示无人可分享。
生成二维码先选有效时长，再展示二维码与冻结快照。每次生成唯一 sceneId；长期有效至所选活动最晚结束。
我的二维码查看有效/过期记录及冻结活动。再次保存保持原 sceneId；本期无手动作废。
二维码详情默认展示完整客户海报，可原位切换纯二维码，并列出保存的三段海报文案。两种效果共用同一 sceneId 与冻结快照；客户海报不展示内部 ID。
制作海报系统模板/上传底图、文案编辑、头像开关、保存与分享。对客户不展示工号、手机号或账号 ID。
用户未绑车组合活动只显示一张大活动卡片，卡券区域整体隐藏。无 VIN 不判断人群包；绑车后不回跳。
用户已绑车原卡片内显示当前 VIN 命中的全部卡券。多子活动命中全部执行；组合参与键为组合活动 ID + VIN。
一键参与一次执行全部勾选活动，抽奖自动完成并只反馈结果。互斥同组仅可选一个；最后触点在成功执行时确认。
查看客户按脱敏手机号、客户编号或 VIN 查询本人来源客户，进入详情逐张看券。只纳入上线后且最终归属当前账号的券实例。
发起活动分享客户详情底部进入既有选择活动页。新二维码不绑定当前客户，可转发；实际领取归属实际参与客户。

P1 客户追踪增量

  • 入口：我的分享数据 → 客户 → 客户列表 → 客户详情 → 发起活动分享。
  • 客户详情展示券实例、来源普通/组合活动、命中子活动、VIN、领取时间和核销状态。
  • 客户卡券使用“已过期”；已过期券保留追踪，真正已失效的券实例不进入客户列表或详情。
  • 再次分享不读取或保存微信好友，不设置“长期未核销”阈值，也不限制员工发起频次。
  • 停用账号不可新建分享；门店管理人员可查看授权汇总，但不能代替来源员工生成二维码。
  • 查看从创建活动到再次分享的完整业务时序图。

用户公开信息

  • 仅展示“由{门店}·{员工姓名}分享”和活动数量。
  • 不展示员工角色、二维码有效时长或截止时间，也不展示员工工号、手机号、账号 ID。
  • 二维码已过期或已失效时仍反馈结果状态，但不展开具体有效期。
  • 用户活动列表隐藏号码级、绑车级、认证级分区与标签。
  • 用户仍可查看二维码内全部活动，准入不足项置灰并提供绑车/认证入口。
