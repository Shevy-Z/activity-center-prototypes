# 组合活动 · 页面状态连线图

双击同目录 `index.html` 即可离线打开，无需安装。

四组共14个状态：政策页（正常、未开始、已结束）、登录弹窗、抽奖页（待抽奖、中奖、未中奖）、领券结果页（原有五种情况，以及同VIN跨手机号领取的两种场景）。沿箭头查看页面关系；新增VIN领取场景支持点击按钮演示。

拖拽平移，滚轮缩放；顶部可定位四类页面，底部“全图”回到总览。卡券长页面完整铺开，静态截图中的按钮不响应业务操作。

这是一份本地评审示意，不连接真实账号、车辆、抽奖或发券接口。原有五种结果状态仍按截图展示，认证级示例为方便看图采用全部展开视图，实际默认折叠规则未改。

## 同VIN跨手机号领取 · 2026-11-26

- 顶部“同VIN领取场景”或页面清单可定位新增的两个绑车级结果页。也可用 `?node=vin-limit-two`、`?node=vin-limit-one` 直接打开。
- 两场景均默认A用户已领1张，B用户通过快捷绑车绑定同一VIN但本人未领，初始按钮均为“立即领取”。按钮按当前用户记录判断，点击时才校验VIN累计限额。
- VIN限领2张：B领取1张成功，VIN累计变为2张，成功后才显示“查看卡券”。再次点击只查看B卡包，不重复发券。
- VIN限领1张：B领取失败，toast为“该VIN已在其他手机号领取卡券，超过限领次数”；不增加领取数，按钮仍为“立即领取”。
- “重置本场景”恢复A已领1张/B未领；两个场景独立，不互相改变记录。所有领取结果仅在本次浏览器页面内模拟。
