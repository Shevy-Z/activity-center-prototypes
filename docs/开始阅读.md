# 活动中心交接包

本目录已从原“卡券中心 + 活动中心 + TCS”综合交接包中整理为活动中心专用版本。

建议按以下顺序阅读：

1. 打开 `index.html`，从总入口进入各原型。
2. 先看项目根目录的 `活动中心1106/index.html`：这是当前新增的最新 Axure，后续设计优先对照其页面结构、业务状态和交互逻辑。
3. 进入“活动中心相关原型”聚合页：所有原型按同一层级展示，可直接查看组合活动分级领取、保客活动创建准入联动、员工分享与二次运营、活动积分、活动奖励、互斥叠加、适用门店和组合活动等内容。SA 动态二维码业务时序已归入员工分享与二次运营。
4. 需要追溯旧版本时，再看 `03_历史原型基线/活动中心` 的 111 页 Axure 基线。

项目范围、目录说明、当前进展和待确认事项见 `01_活动中心说明/活动中心项目梳理.md`。需要核对上一任同事的原始交接口径时，看 `01_活动中心说明/原交接文档_活动中心节选.md`；需要查原始需求条目时，看 `04_参考资料/活动需求台账`。

注意：原型均为静态演示和评审材料，使用 Mock 数据；有原型不等于接口已联调、研发已完成或已经上线。当前进度依据截至 2026-10-21 的交接快照，接手后仍需向研发、测试和业务负责人复核。
